## 2. Detailed Description

```text
Extension Drawer is a fast, modern, and privacy-first extension manager that helps you organize, group, and automate your browser extensions.

Whether you use dozens of developer tools, privacy utilities, shopping helpers, or work plugins, Extension Drawer gives you complete control over your browser environment with clean visual management and one-click bulk controls.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ INSTANT EXTENSION CONTROLS
• Enable or disable extensions with high-contrast, responsive switches.
• View extensions in 3 flexible layouts:
  - Big Tile (2-column balanced cards with metadata)
  - List View (compact 44px rows for high-density scanning)
  - Tile View (compact grid with hover/focus action overlays)
• Search extensions in real time by name, category (extensions, apps, themes), or runtime state.
• Bulk visibility controls (Enable All / Disable All) with multi-level Undo & Redo.
• Operational summary pill displaying live running counts (e.g., "12 / 24 running · 1 needs attention").

🏷️ COMMAND-BASED GROUPS
• Create custom groups for Work, Shopping, Development, Privacy, Social, or Daily workflows.
• Instant [ OFF | ON ] bulk commands: turn an entire group on or off in a single click.
• Real-time running status counters on every group card (e.g., "5 / 6 running").
• Overlapping groups and individual extension toggles work together seamlessly without state fighting.
• Choose from over 3,000 self-hosted Material Symbols icons, curated recommended icons, or custom image uploads.

🌐 AUTOSTATE AUTOMATION
• Automatically or assistively enable and disable extension groups based on the website URL you visit.
• Flexible matching using domain wildcards (e.g., *.example.com) or regular expressions.
• Background automation with optional desktop notification prompts for manual confirmation.
• Privacy: AutoState reads the active tab URL locally to match your own rules. Extension Drawer does not store those URLs in its history or configuration and does not send them to the developer or third parties. Installed-extension metadata is also processed locally for extension management.

📜 HISTORY & DIAGNOSTICS
• Track timestamped audit logs of extension installations, updates, enables, and disables.
• Inspect extension permissions, host access, installation type, and direct Chrome Web Store links.

🎨 APPEARANCE & CUSTOMIZATION
• Seamless support for System (auto dark/light), Light, and Dark themes.
• Customizable accent color presets (Chrome Blue, Indigo, Purple, Emerald, Orange, or Custom Hex).

💾 100% LOCAL PRIVACY & BACKUP
• Export and import your groups, rules, and settings as standard JSON files.
• No telemetry or background transmission of browsing activity or extension-management data.
• Zero advertising, zero user accounts, and zero remote code execution.
• All configuration remains strictly on your local machine.
```
