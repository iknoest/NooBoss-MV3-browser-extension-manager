# Extension Drawer v1.2.0 · Developer Workspace, ZIP Downloads & Guided Getting Started

**Release Tag:** `v1.2.0`  
**Target Architecture:** Manifest V3 (Chrome 116+)  
**Date:** October 4, 2026  

Extension Drawer 1.2.0 is a major milestone release introducing an optional Developer Workspace, universal Chrome Web Store package ZIP downloads, an interactive 6-step Getting Started walkthrough, unified Site Rules terminology and automation lifecycles, and refined user-centered catalog sorting.

---

## What's New

### 🧭 Guided Getting Started Walkthrough
- Built-in interactive 6-step walkthrough covering Extensions, Groups, Site Rules, History, Backup & Data, and the optional Developer Workspace.
- Accessible directly on first run or re-launched anytime via **About → Getting started**.

### 🛠️ Developer Workspace · Optional
- Dedicated hub for extension authors, completely hidden by default until explicitly opted into in Settings.
- Connect local unpacked builds with one-click reload triggers and manifest diagnostics.
- Quick navigation links directly to GitHub repositories and Chrome Web Store listings.
- Read-only Store listing analytics integrating Google Analytics 4 (GA4) property data via Google OAuth to inspect 28-day active users, new users, views, and engagement rates.

### 📦 Chrome Web Store Package ZIP Downloads
- Download unpacked `.zip` archives of any supported extension directly from official Chrome Web Store distribution endpoints.
- Client-side extraction and archive creation without third-party intermediary servers.

### 📜 History Filtering & Canonical CSV Export
- Comprehensive management history log tracking installation, update, enable, and disable events.
- Real-time event filters and extension name search.
- Canonical CSV export centralized under **Options → Backup & Data**.

### 🔀 User-Centered Catalog Sorting
- Restructured sorting options tailored to extension management workflows:
  - *Recently installed / updated*
  - *Enabled first*
  - *Recently changed*
  - *Name A–Z*

---

## Improvements & Fixes

### 🌐 Site Rules Modernization
- Retired legacy "AutoState" naming across all user-facing surfaces in favor of clear, modern **Site Rules** terminology.
- Simplified rule timing models: *Temporary while open* (reverting on close) and *One-time on open*.
- Live dynamic behavior preview box providing plain-language summaries of exact rule effects before saving.

### 🏷️ Command-Based Groups & Live Status
- Real-time `X / Y running` operational indicators on every group card and catalog summary badge.
- Harmonious group toggling without persistent desired-state loops or conflicting membership issues.

### 🎨 Responsive Action Containment & Material Consistency
- Resolved Tile view control containment: two-tier hover layout separates toggle switches from action buttons, eliminating overflow at all supported manager widths.
- Crisp Material Symbols styling, high-contrast enabled/disabled states, and responsive themes (System, Light, Dark).

---

## Privacy & Permissions Architecture

- **Local-First Core**: Routine extension management, group commands, Site Rules evaluation, and history logging operate 100% locally in browser memory and `chrome.storage.local`.
- **Zero First-Party Telemetry**: Extension Drawer does not run tracking servers, behavioral analytics, or advertising infrastructure.
- **Explicit User Opt-In**: Optional features connect to external Google services only after deliberate user action:
  - Google Analytics connection requests `identity` and Google Analytics Data API host access via Google OAuth.
  - Store package download requests `downloads` and Google Web Store package host access.
  - Non-developer users who do not use these features are never prompted.

## Lineage & Origin

Extension Drawer is an independently maintained, open-source Manifest V3 continuation inspired by the classic **NooBoss** extension originally created by **AInoob**. It modernizes the workflow for modern browser standards while preserving the spirit of flexible, user-controlled extension management.
