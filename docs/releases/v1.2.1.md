# Extension Drawer v1.2.1 · Safer Settings, Better Groups & Quality-of-Life Improvements

**Release Tag:** `v1.2.1`  
**Target Architecture:** Manifest V3 (Chrome 116+)  
**Date:** October 10, 2026  

Extension Drawer 1.2.1 is a targeted post-launch quality-of-life and reliability patch that resolves extension options page access errors, establishes Tile as the clean fresh-install default, makes missing group members identifiable and actionable with durable metadata caching and reversible removal, and introduces project support shortcuts.

---

## Fixed

- **Safer Extension Settings / Options Navigation**: Opening settings for disabled extensions no longer produces Chrome's blocked error page (`ERR_BLOCKED_BY_CLIENT`).
- **Defensive Enable-and-Open Confirmation Flow**: Clicking Settings on a disabled extension now displays an explicit confirmation dialog (`Enable extension to open settings?`) before taking any action. The extension is enabled and its settings page opened only after user confirmation; canceling makes zero state changes.
- **Hidden Settings for Extensions Without Options Pages**: Extensions that declare no `optionsUrl` now cleanly hide the Settings action rather than presenting a dead button.
- **Service Worker Protective State Validation**: The background service worker performs defensive checks on extension enabled state and options URL presence prior to opening tabs, preventing blind navigations.

---

## Improved

- **Tile View Default for Fresh Installs**: Fresh profiles and installations without a stored preference now open in the compact Tile view by default. Persisted user preferences (`List`, `Big Tile`, `Tile`) are strictly respected and preserved across restarts.
- **Durable Known-Extension Metadata Cache**: Introduced a lightweight local registry (`nooboss_known_extensions`) in `chrome.storage.local` that records extension names, versions, and types on authoritative inventory updates. Last-known identities persist even if activity history is cleared or an extension is uninstalled.
- **Identifiable & Actionable Missing Members**: Focused group views and group editors now display a dedicated `Missing from Chrome (N)` section identifying missing extensions by their last-known name, extension ID, and status pill.
- **Reversible Remove-from-Group with Undo**: Missing members can be pruned directly from groups with instant visual feedback and a reversible `Undo` toast, allowing immediate restoration without affecting extension runtime state or other groups.
- **Explicit Web Search for Unknown Extensions**: Genuinely unidentified missing extension IDs feature a user-initiated `Search web` action that opens an exact quoted Google Search (`chrome extension "<EXTENSION_ID>"`) in a new browser tab. Operates strictly upon user click with zero background scraping, zero network requests before click, and zero additional permissions.
- **Inventory-Loading Protection**: Group runtime counters and missing-member lists now strictly distinguish `loading`, `ready`, and `error` inventory states. Temporary loading latency or management API errors never falsely mark members as missing.
- **Project Support Shortcuts**: Added a restrained `🍻 Buy me a Beer` shortcut in the top navigation and a canonical `Support the project` section in the About page, safely linking to the project's Buy Me a Coffee page in a normal browser tab without third-party widgets or tracking scripts.
- **Updated Capability Documentation**: Refreshed Backup & Data copy in the About page to explicitly reflect support for both importing and exporting activity history.
