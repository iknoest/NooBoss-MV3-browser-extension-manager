## 2. 60-Second Video Storyboard Breakdown

1. **Scene 1 (0:00 – 0:05) · Hook & Identity**
   - *Visual*: Centered Extension Drawer brand icon with subtle pulsing glow, transitioning to reveal high-density Tile view catalog.
   - *Caption*: `Managing 100 Chrome extensions shouldn't be this hard.`
2. **Scene 2 (0:05 – 0:16) · Catalog Management & Control**
   - *Visual*: Live Tile view grid in Extension Drawer 1.2.1. Search filter typing, instant enabled/disabled toggle switch, user-friendly sorting.
   - *Caption*: `Search, sort and control your extensions.`
3. **Scene 3 (0:16 – 0:28) · Command-Based Groups**
   - *Visual*: Focused group view (*Development Stack*). Real-time running counter badge (`5 / 6 running · 1 missing`). One-shot `[ OFF | ON ]` execution. Reversible missing-member cleanup with 5s `Undo` toast feedback.
   - *Caption*: `Switch whole workflows with one click.`
4. **Scene 4 (0:28 – 0:40) · Automate with Site Rules**
   - *Visual*: Site Rules manager. Context-aware automation targeting websites (e.g. `github.com`). Temporary while open rule lifecycle and live plain-language preview.
   - *Caption*: `Only run extensions where you actually need them.`
5. **Scene 5 (0:40 – 0:48) · History & Portable Backup**
   - *Visual*: Comprehensive audit history log with event filters. Backup & Data section demonstrating JSON configuration export/import and safe CSV history import.
   - *Caption*: `History and portable local backups.`
6. **Scene 6 (0:48 – 0:56) · Developer Workspace (Optional)**
   - *Visual*: Developer Workspace tab showing local unpacked project reload, repository and store quicklinks, read-only 28-day GA4 analytics, and package ZIP download.
   - *Caption*: `Built-in tools for extension developers.`
7. **Scene 7 (0:56 – 1:00) · Brand End Card**
   - *Visual*: Brand lockup with official Extension Drawer logo.
   - *Copy*: `Extension Drawer` · `Free & open source` · `Chrome Web Store · GitHub`

## 3. Store Promotional Graphics Specifications

### Small Promo Tile (440 × 280)
- **Filename**: `small-promo-tile-440x280.png`
- **Target Dimensions**: 440 × 280 pixels
- **Format**: 24-bit PNG (no transparency)
- **Design Principles**:
  - Brand-first: Bold 3D layered drawer/card visual motif with official Extension Drawer logo.
  - Saturated brand accent (`#1a73e8` / `#3b82f6` radiant lighting) against dark slate background (`#090d16`).
  - Minimal text, maximum visual legibility at small scale.

### Marquee Promo Tile (1400 × 560)
- **Filename**: `marquee-promo-tile-1400x560.png`
